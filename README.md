# Student Score Analysis

This is a beginner-level Python project where I explored a small dataset of student study hours and scores to find patterns and insights.

## Dataset

- Source: [CSV link](https://raw.githubusercontent.com/AdiPersonalWorks/Random/master/student_scores%20-%20student_scores.csv)
- Features:
  - Hours: Number of hours studied
  - Scores: Score obtained

## Tools Used

- Python
- Pandas
- Matplotlib

## What I Did

- Loaded and explored the dataset
- Checked for missing values and dataset summary
- Visualized the relationship between study time and score
- Calculated correlation between Hours and Scores

## Key Observations

- Students who studied more generally scored higher
- There is a strong positive correlation between hours studied and score

## My Learning

This project helped me practice:
- Reading and cleaning a dataset using Pandas
- Creating plots using Matplotlib and Seaborn
- Documenting and organizing a basic data project
